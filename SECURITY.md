# Security policy

go-arlo follows [Oiko's security policy](https://github.com/llehouerou/oiko/blob/main/SECURITY.md):
supported versions, what a report needs, and what to expect.

To report a vulnerability in go-arlo, use this repository's private vulnerability reporting:
[report a vulnerability](https://github.com/llehouerou/go-arlo/security/advisories/new). Never
report one in a public issue or discussion.
